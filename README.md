# 🏏 CricketArena

**CricketArena** is a cricket website built to provide cricket fans with an engaging and user-friendly platform for exploring cricket news and cricket-related content.

🌐 **Live Demo:** https://rizwan-bm.github.io/Cricketarena/

## 🚀 Features

- 📰 Cricket news section
- 🏏 Cricket-themed homepage
- 🎨 Modern and attractive user interface
- 📱 Responsive website design
- ⚡ Interactive elements and smooth navigation

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 📸 Live Website

Visit the project: [CricketArena](https://rizwan-bm.github.io/Cricketarena/#news)

## 💻 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Rizwan-bm/Cricketarena.git
   ```

2. Open the project folder in Visual Studio Code.
3. Run `index.html` in your browser or use the Live Server extension.

## 🎯 Project Purpose

This project was created to practice frontend web development and build a cricket-themed website for my developer portfolio.
